# 36 Presents Interactive Sphere — Logo Edition

A Streamlit/Three.js interactive particle sphere with a 36 PRESENTS brand mark fixed visually in the center.

Features:
- Transparent particle sphere
- No solid globe
- No blue outer shell
- Slow rotation
- Cursor interaction
- Drag rotation
- Subtle orbital lines
- 36 PRESENTS center brand mark

IMPORTANT:
The center mark in this version is a clean text-based representation ("36 PRESENTS").
For the exact official 36 Presents logo artwork, replace the center HTML with the official SVG/PNG brand asset.

Run:
    pip install -r requirements.txt
    streamlit run app.py
